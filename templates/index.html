    How it works

    1. 1

      Upload

      Choose a PDF or a photo of your notes. Or just paste text.

    2. 2

      Extract

      PyPDF2 reads PDFs. Tesseract OCR reads text from images.

    3. 3

      Translate

      Keep English, or switch to Hindi or Marathi.

    4. 4

      Listen

      Play, pause, change speed from 1× to 5×, set the volume.

    5. 5

      Bookmark

      Save any spot and jump back to it later.

    About this project

    A Python mini project that turns documents into audiobooks, so reading becomes listening.

    Built with
    Python, Flask, PyPDF2, Tesseract OCR, gTTS, deep-translator, JavaScript
    Languages
    English, Hindi, Marathi
    Your files
    Processed in memory on your own computer and never saved. Only the text is sent to Google for translation and voice, so you need internet.
